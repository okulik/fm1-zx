# Licensing

FM-1 ZX is free software under the GNU General Public License, version 3 or (at your option)
any later version (`GPL-3.0-or-later`, `LICENSE`). Some parts are other people's work under
their own licences. Every file carries its licence as an SPDX tag or in `REUSE.toml`
(`reuse lint` checks it), and the licence texts are in `LICENSES/`.

How a part is combined decides what it means for the whole:

- **linked into the image**: compiled and linked into `fmzx_app.bin`, the firmware the FM-1 runs;
- **separate program in the package**: shipped side by side in the update package, never linked
  with our code;
- **data**: bytes the firmware or the package carries and reads, not code linked with ours;
- **host tool**: runs on the developer's computer only; nothing of it is in the image or the
  package.

### The image

`fmzx_app.bin` combines our GPL-3.0-or-later code with LGPL-3.0-or-later, 0BSD and MPL-2.0 code,
all compatible with it; the image as a whole is under GPL-3.0-or-later. The source of every part
is this repository, so anyone given the image can rebuild it, also with a changed Z80 library
(LGPL-3.0 section 4). The ROM stays under Amstrad's permission, which covers it only unmodified.

### The update package

The `.fwsc` package is an aggregate of separate works, side by side in one container: the image
and the game pack (above), Felucca's update loader (GPL-3.0-only; its complete source is
`third_party/felucca-loader/`, also at <https://github.com/hugelton/Felucca> commit
`a53ecf428c29c780108fd70a31b71a32a6b5c313`) and the three SDK files (Apache-2.0). Whoever passes a
package on should pass on with it, or point to, this repository at the same commit (the source
of the GPL parts and the build of every byte), `LICENSES/` (in particular `GPL-3.0-or-later.txt`,
`GPL-3.0-only.txt`, `LGPL-3.0-or-later.txt`, `MPL-2.0.txt`, `MIT.txt`,
`CC-BY-SA-2.0.txt`), the SDK files' licence text (`docs/third-party/AC79-SDK-Apache-2.0.txt`;
`tools/make-packages` puts a copy, `AC79-SDK-Apache-2.0.txt`, next to the packages) and this file
with the games' attributions. Nothing in the repository itself is under the Apache License.

## The built-in games

The game is an unmodified file with its licence texts and statements next to it.

**Castaway** by Juan J. Martínez (2016), `third_party/games/castaway/`. Three licence statements
exist:

1. the release archive's `README.txt` (`README.release.txt`): MIT;
2. the source repository's `README.md` (`README.upstream.md`): code under GPL 3.0, assets under
   CC-BY-SA 2.0;
3. the game's web page: the site-wide footer "CC BY NC SA 4.0, unless stated otherwise", which
   the two statements above do state otherwise.

The tape is the release's, so it is taken under its MIT licence; the repository's licence covers
it too (SPDX `MIT OR (GPL-3.0-only AND CC-BY-SA-2.0)`). Attribution: Castaway by Juan J. Martínez,
<https://www.usebox.net/jjm/castaway/>.
